# One-Line Office Joke

A single-line office joke built for make.fun's "One-Line Office Joke Laugh-Off" bounty. The joke plays on a familiar IT-support moment — asking for extra screen space — and twists it with a clean reversal, steering clear of the usual meeting, email, printer, coffee, and Monday clichés. It lands in one read, with every word earning its place.

## Run it

```sh
node main.ts
```

This writes the joke to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt`).
